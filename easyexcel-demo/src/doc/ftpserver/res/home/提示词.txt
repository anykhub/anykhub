中医药膳养生系统 - 项目提示词
项目名称： 智慧本草 - 个性化中医药膳养生平台

项目概述： 构建一个基于现代Web技术的中医药膳养生综合服务平台，融合传统中医体质辨识理论与现代信息技术，为用户提供个性化的养生指导和药膳推荐服务。系统通过九型体质智能评测、药材药膳知识库、养生资讯分享等功能模块，帮助用户科学认知自身体质，获取专业的中医养生建议。

一、系统架构设计
前端技术栈：

Vue.js 3.x - 渐进式前端框架
HTML5 + CSS3 - 页面结构与样式
Element Plus / Ant Design Vue - UI组件库
Axios - HTTP请求库
Vue Router - 前端路由管理
Vuex / Pinia - 状态管理
后端技术栈：

Spring Boot 2.x - 微服务框架
Spring MVC - Web层框架
MyBatis - 持久层框架
MySQL 8.0 - 关系型数据库
Redis - 缓存中间件（可选）
JWT - 用户认证授权


二、功能模块详细设计
用户端功能模块
1. 首页门户

展示平台核心功能导航
推荐热门药膳方案和养生文章
展示中医养生日历（节气养生提醒）
用户体质概览卡片（已登录用户）
2. 体质评测问卷

基于《中医体质分类与判定》标准设计问卷
包含60道多维度评测题目
智能评分算法，生成体质分析报告
历史评测记录查询与对比
3. 九型体质档案

详细展示九种体质特征（平和质、气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质）
每种体质的成因、表现、调养原则
可视化体质雷达图
个性化养生建议推送
4. 药材知识库

药材分类浏览（按功效、性味、归经分类）
药材详情页（功效、用法、禁忌、图片）
智能搜索与筛选功能
药材收藏与笔记功能
5. 药膳方案库

按体质、季节、功效分类展示药膳
药膳详情（食材配方、制作步骤、适用人群、功效说明）
用户评分与评论系统
个性化药膳推荐（基于用户体质）
6. 养生知识中心

养生文章分类（四季养生、经络养生、情志养生等）
文章详情页（富文本展示、图文并茂）
文章点赞、收藏、分享功能
知识搜索与标签筛选
7. 互动交流社区

用户发帖、回复、点赞功能
话题分类（养生心得、药膳分享、体质调理等）
用户个人主页与关注系统
敏感词过滤与内容审核
管理端功能模块
1. 角色权限管理

管理员账号管理（增删改查）
角色定义与权限分配（超级管理员、内容管理员、审核员）
操作日志记录与查询
用户账号状态管理（启用/禁用）
2. 药材分类管理

药材分类的增删改查
多级分类树形结构管理
分类排序与状态控制
批量导入药材数据
3. 药膳分类管理

药膳分类体系维护
按体质、功效、季节等多维度分类
药膳信息的审核与发布
药膳推荐权重配置
4. 知识分类管理

养生知识分类维护
文章审核与发布管理
热门文章推荐设置
知识标签管理
5. 互动内容管理

用户发帖内容审核
违规内容处理（删除、隐藏）
评论管理与举报处理
社区公告发布





三、核心技术实现要点
1. 后端实现

- 使用 Spring Boot 构建 RESTful API
- MyBatis 实现数据持久化，支持动态SQL
- 统一异常处理与返回格式封装
- JWT实现无状态用户认证
- AOP实现日志记录和权限控制
- 数据库连接池优化（Druid/HikariCP）
2. 前端实现

- Vue 组件化开发，提高代码复用性
- Vue Router 实现前端路由与权限控制
- Vuex/Pinia 管理全局状态（用户信息、体质数据等）
- Axios 拦截器统一处理请求和响应
- 响应式布局，适配PC和移动端
- ECharts 实现体质雷达图等数据可视化
3. 数据库设计

核心表设计：
- user（用户表）
- constitution_questionnaire（体质问卷表）
- constitution_result（体质评测结果表）
- herb（药材表）
- herb_category（药材分类表）
- medicated_diet（药膳表）
- diet_category（药膳分类表）
- knowledge（养生知识表）
- knowledge_category（知识分类表）
- community_post（社区帖子表）
- comment（评论表）
- admin_user（管理员表）
- role（角色表）
- permission（权限表）








四、项目亮点与创新点
智能体质辨识算法：基于中医理论的评分模型，精准判定用户体质类型
个性化推荐引擎：根据用户体质智能推荐适合的药膳和养生方案
知识图谱构建：建立药材-功效-体质-药膳的关联网络
数据可视化：使用雷达图、趋势图等直观展示体质变化
社区互动：打造养生爱好者交流平台，增强用户粘性









五、开发建议
数据准备：收集整理中医药材、药膳、体质相关的专业资料
UI设计：采用中国风设计元素，体现中医文化特色
安全性：做好SQL注入防护、XSS防护、密码加密存储
性能优化：使用Redis缓存热点数据，分页查询优化
测试完善：编写单元测试和集成测试，确保系统稳定性
